# ShardStore
A distributed key-value storage engine

This project explores:
- Concurrent request processing
- Durable Storage and crash recovery
- Data partitioning and replication
- Performance characterization
- Correctness under controlled failure scenario

# Project Status

Currently in foundation phase

# Development

Requirements:
- Rust toolchain
- Cargo

Build:

    cargo build

Test:

    cargo test
